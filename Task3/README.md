# Continual learning: Naive vs EWC vs Cumulative

Подготовительная часть проекта по непрерывному обучению для детекции дефектов дорог. Стратегии сравниваются на PermutedMNIST (domain-incremental) и SplitCIFAR10 (class-incremental) с LeNet, библиотека Avalanche.

Метрики: stream accuracy, mean experience accuracy, forgetting. Итоговая таблица и выводы — в конце `Task3_CL_Mary.ipynb`.
